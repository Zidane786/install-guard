# Security policy

Please report security problems **privately** through GitHub:
**Security → Report a vulnerability** on https://github.com/Zidane786/install-guard
(private vulnerability reporting is enabled). Don't open a public issue for security bugs,
and especially not for a way to get an install or download past the guard.

Useful areas to look at: command parsing and unwrapping, source resolution (registries, config
files, URLs), the approval flow for loosening the policy, and the launchers' behaviour when
Python is missing.

You'll get an answer as soon as possible; fixes are released as a new plugin version with a
CHANGELOG entry.
